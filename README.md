# Little Lemon Restaurant App

A responsive React web app for the Little Lemon restaurant.

## Features
- Responsive homepage
- Booking form with validation
- Booking confirmation page
- Semantic HTML and accessibility improvements
- Unit tests for reducer and form validation

## Tech Stack
- React
- React Router
- CSS
- Jest
- React Testing Library

## Setup
1. Clone the repository
2. Run `npm install`
3. Run `npm start`

## Run tests
`npm test`
